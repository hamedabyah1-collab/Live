## نظرة عامة

**كاشف الأشياء الذكي** هو تطبيق Android متطور يستخدم أحدث تقنيات الذكاء الاصطناعي للتعرف على الأشياء من خلال كاميرا الجوال مباشرة. يوفر التطبيق معلومات تفصيلية وشاملة عن كل شيء يتم اكتشافه باللغة العربية.

## المميزات ✨

### 🎯 التعرف الذكي
- **رؤية فورية**: استخدام الكاميرا في الوقت الفعلي
- **دقة عالية**: تقنيات ML Kit و Gemini AI
- **تغطية شاملة**: التعرف على الحيوانات، النباتات، الأطعمة، الأشياء، المركبات، والمزيد

### 📊 معلومات تفصيلية
- **الاسم والوصف**: معلومات دقيقة بالعربية
- **التصنيف**: تصنيف تلقائي للأشياء
- **حقائق مثيرة**: معلومات إضافية مفيدة
- **نسبة الثقة**: عرض دقة التعرف

### 💾 إدارة السجل
- **حفظ تلقائي**: حفظ جميع النتائج
- **سجل كامل**: عرض جميع عمليات الكشف السابقة
- **إدارة سهلة**: حذف عناصر فردية أو مسح الكل

### 🎨 واجهة عصرية
- **Material Design**: تصميم حديث وجذاب
- **سهولة الاستخدام**: واجهة بديهية وبسيطة
- **أداء سلس**: تجربة مستخدم سريعة

### 🔧 وظائف إضافية
- **المشاركة**: مشاركة النتائج مع الآخرين
- **الفلاش**: دعم الفلاش للإضاءة المنخفضة
- **تبديل الكاميرا**: استخدام الكاميرا الأمامية أو الخلفية

## التثبيت 📥

### المتطلبات
- Android 7.0 (API 24) أو أحدث
- كاميرا
- اتصال بالإنترنت
- مساحة: 50 ميجابايت

### خطوات التثبيت
1. حمّل ملف APK من [الإصدارات](releases)
2. افتح الملف على جهازك
3. اسمح بالتثبيت من مصادر غير معروفة
4. اتبع تعليمات التثبيت
5. افتح التطبيق واستمتع!

4. وجه الكاميرا نحو أي شيء
5. اضغط على زر الكاميرا

- ✅ استخدم اتصال إنترنت جيد

## التقنيات 🛠️

### البنية التقنية
- **اللغة**: Kotlin
- **الحد الأدنى**: Android 7.0 (API 24)
- **الإصدار المستهدف**: Android 14 (API 34)

### المكتبات الرئيسية
| المكتبة | الوظيفة |
|---------|---------|
| **CameraX** | إدارة الكاميرا |
| **ML Kit** | التعرف الأولي على الأشياء |
| **Gemini AI** | التحليل التفصيلي |
| **Room** | قاعدة البيانات المحلية |
| **Retrofit** | الاتصال بالإنترنت |
| **Coroutines** | العمليات غير المتزامنة |
| **Material Components** | واجهة المستخدم |

### المعمارية
```
MVVM Architecture
├── UI Layer (Activities)
├── ViewModel Layer
├── Repository Layer
└── Data Layer (Room + Network)
```

## التطوير 👨‍💻

### إعداد بيئة التطوير

#### المتطلبات
- Android Studio Hedgehog أو أحدث
- JDK 17
- Android SDK 34

#### الخطوات
```bash
# 1. استنساخ المشروع
git clone <repository-url>
cd AIObjectDetector

# 2. افتح في Android Studio
# File → Open → اختر المجلد

# 3. أضف مفتاح Gemini API
# في GeminiAnalyzer.kt:
private val apiKey = "YOUR_API_KEY"

# 4. بناء المشروع
./gradlew build

# 5. تشغيل التطبيق
./gradlew installDebug
```

### البناء للإنتاج
```bash
# إنشاء APK
./gradlew assembleRelease

# إنشاء AAB
./gradlew bundleRelease
```

### الاختبار
```bash
# Unit Tests
./gradlew test

# Instrumentation Tests
./gradlew connectedAndroidTest
```
